# Minikano OpenWrt 屏幕接入

本分支基于 infoscreen `7e031de`，从 E5 仓库 `8b891d81` 同步共用屏幕组件。
完整提交、文件 SHA256、原生源码摘要见 [E5-SOURCE.json](E5-SOURCE.json)。
原有 infoscreen 及 Phone 的许可、来源记录保留。

原生解析回归另发现并修复：运营商 UCS2 名称含 U+0000 时不应截断为前半段，
现在保留原始异常值。此为独立仓库的额外修正，来源记录单独列出；
需回迁到 E5 后才能再次从 E5 导入，防止重新引入已修复问题。

## 同步内容

- 全部七款屏幕机型共用的界面、API、APN、频段／SIM 控制入口、短信未读与流量视图。
- 标题栏加载、主页及状态栏布局、主题、手势／列表滑动、重复 DOM 更新优化。
- 息屏轮询暂停、原生事件传输、充电插拔唤醒、实体键电源菜单和操作回执。
- 低唤醒原生屏幕电源、双卡状态、通话状态／屏幕 HTTP 传输辅助程序。
- 配套 Phone 插件只保留一个内置副本，APN 脚本并入 app.js，不再另放同内容的 apn.js。

使用本仓库原来的 `root/` 和 `tools/stage.py` 结构；不再复制 E5 的整套目录、
内核、驱动、安装器、ModemManager 或机型固件。硬件差异仍由机型固件管理。

## 平台依赖

需要与本分支匹配的 E5 OpenWrt 后台，包括 `mu300.common` 看板公共模块、
`unisoc.modem`／APN／流量 RPC、`e5status`、AT 所有权服务、
`/usr/libexec/unisoc-modem/hotspot.uc`、充电／CPU／USB／声音／蓝牙控制及原厂音频运行库。
这些由 E5 固件提供，不在信息屏仓库再维护一套。

`t551m-*` 名称是现有兼容接口，不表示给其他机型安装 T551M 驱动。
实体拨号键由手机外壳交给 Phone，通用插件不能截走；实体电源键由外壳处理，
短按松手息／亮屏、长按电源菜单。普通插件的 capturePower 请求不覆盖这条硬件策略。
锁屏／息屏时其他按键不唤醒，来电及充电插拔按原有设置处理。
三份原生程序均为 AArch64：屏幕电源静态链接；SIM 与通话辅助依赖 glib2、libjson-c5，
音频硬件使用平台的 ALSA 库。对应包已列入 packages.txt。

本仓库提交生成后的界面与服务文件，可直接用于离线 staging；
`src/native/` 同时保留七份原生源码，`native-build.json` 校验源码、构建器与 ELF 配对。
不要将本分支屏幕包直接用于缺少上述后台的旧固件。

## 构建与同步

检查现有原生文件（不编译、不连接设备）：

```sh
python3 tools/build-native.py --check
python3 tools/stage.py --root /path/to/separate-offline-root
```

需重编原生服务时，显式指定已有的 OpenWrt SDK volume。此命令不会下载镜像、
创建／复制 SDK 或内核；源码只读挂载，编译输出仅写本仓库对应程序和构建记录：

```sh
python3 tools/build-native.py --sdk-volume e5-openwrt-src \
  --toolchain toolchain-aarch64_generic_gcc-14.3.0_musl --image debian:trixie
```

重新从已提交的 E5 源码导入：

```sh
python3 tools/sync-e5.py --source /path/to/e5-linux
python3 tools/build-native.py --check
```

如原生输入已改变，需用上面的构建命令更新源码／ELF 配对记录。
导入只选择屏幕相关文件，不复制用户配置、联系人、短信、号码、IMEI 或 NV。

维护时可直接修改本仓库 root/ 和 src/native/，不依赖本机另一个 E5 目录才能构建或 staging。
sync-e5 是显式维护工具；不要用它覆盖尚未回迁到 E5 的本仓库改动。

没有修改 `.version`，本次只推分支，不创建 tag、Release 或更新线上包。
源码／桌面测试通过不代表已在每台硬件上重新安装验收。

首次接入建议随配套固件／系统补丁一起更新。旧屏幕更新器未实现运行中 ELF 的原子替换，
不要拿本分支包经旧屏幕更新器完成首次迁移。本分支的安装／更新路径已改成先解包校验，
逐文件同目录重命名替换，支持运行中原生程序，并保留用户插件的 web-root 链接目标；
随后重启受影响的屏幕辅助服务。没有为这次导入发布正式更新包。
